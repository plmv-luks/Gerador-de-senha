# Gerador de Senha

gerador de senha que roda no navegador, sem servidor e sem enviar nada pra lugar nenhum.

- dois modos: senha aleatória ou frase com palavras
- tamanho de 4 a 64 caracteres
- maiúsculas, minúsculas, números e símbolos, com quantidade mínima de cada
- caracteres pra sempre incluir ou nunca usar
- opção pra evitar caracteres parecidos (l, 1, O, 0)
- frase com quantidade de palavras, separador e número no final
- medidor de força pela entropia
- copia com um clique

pra usar é só abrir o `index.html`.
