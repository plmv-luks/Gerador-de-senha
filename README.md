# Gerador de Senha

gerador de senha que roda direto no navegador, sem servidor. nada sai do seu computador.

dá pra gerar senha aleatória ou frase com palavras, escolher o tamanho e os tipos de caractere, usar o tema escuro e copiar com um clique. as configurações ficam salvas no navegador, as senhas não.

pra usar é só abrir o `index.html`.
